Questions

Plain answers.

Is Mynah a subscription?

No. Mynah is planned as a one-time lifetime license for the Mac app.

Does Mynah need cloud transcription?

No cloud service is required for the core local dictation loop.

Why does Mynah need Accessibility?

macOS requires Accessibility permission for Mynah to place text into the active app.

Does Mynah work when the window is closed?

Yes. Mynah is designed as a menu-bar utility with background runtime behavior.
