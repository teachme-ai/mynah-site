How Mynah Achieves Sub-Millisecond TTFA

Persistent Warm Standby Stream

CoreAudio HAL queries on macOS block for 1.2+ seconds due to synchronous IPC roundtrips with the OS audio daemon. Mynah warms the audio input stream at launch in a dedicated background worker, keeping the hardware open and ready for instantaneous capture.

300ms Circular Pre-Roll Buffer

When you hold the Fn key, macOS requires 120ms to distinguish a standalone press from a system hotkey chord. Mynah continuously cycles audio into an in-memory lock-free ring buffer. When dictation triggers, the pre-roll is drained into the writer immediately, preventing initial word clipping.

Native Apple Metal whisper.cpp Core

Transcriptions run strictly in native C++ and Rust on your Mac's GPU and Apple Neural Engine. Eliminating Node.js, Electron, and browser Web-Audio bridges frees up system resources for an ultra-lean memory footprint.
