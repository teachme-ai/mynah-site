Install correctly

01

Open the DMG

Double-click the downloaded file to mount the Mynah disk image.

02

Drag to Applications

Drag Mynah.app into your Applications folder. Do not run it from Downloads, Desktop, or the DMG itself.

03

Launch and approve

Open Mynah from Applications. Approve the macOS security prompt, then grant Microphone and Accessibility when asked.

What to expect on first launch

Security prompt Mynah is not from the App Store. macOS may ask you to confirm before opening it. If blocked, go to System Settings → Privacy & Security and click Open Anyway.
Microphone macOS will ask for Microphone access the first time you try to dictate. Approve it to enable Fn recording.
Accessibility Approve Accessibility in System Settings → Privacy & Security → Accessibility to let Mynah paste at your cursor.
Menu bar Mynah lives in the menu bar. Closing the window does not quit the app — the icon stays available and Fn keeps working.
macOS says it can't check Mynah for malicious software

Open System Settings → Privacy & Security, find the Mynah message, and click Open Anyway. Then launch Mynah again from Applications.

I previously used SpeakPaste

Mynah is a new app identity. Remove old SpeakPaste permission entries from Accessibility in System Settings and approve Mynah fresh.

Fn does nothing after install

Confirm both Microphone and Accessibility are enabled in System Settings. Quit and reopen Mynah from Applications. Test in TextEdit or Notes.
